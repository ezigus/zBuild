## Changes made in this run (iteration 8)

### Fixed stale assertions + added shape-change-paths check

**File:** `plugins/claim-coordinator/github-labels/tests/claim-coordinator-unit-test.sh`

**Problem 1 (issue-acceptance finding 1):** The test at the top of the file checked
`grep -q "claimed:" "$labels_file"` (old format: `claimed:<machine>`). On new code
the label is `zbuild:claimed`, which does NOT contain the substring `claimed:` (there
is no colon after "claimed"), so the old assertion fires as `assert_fail`.

**Fix:** Replaced:
```bash
if grep -q "claimed:" "$labels_file" 2>/dev/null; then
    assert_pass "claimed label contains 'claimed:' prefix"
```
With:
```bash
if grep -Fxq "zbuild:claimed" "$labels_file" 2>/dev/null; then
    assert_pass "label is exactly zbuild:claimed (no machine name)"
```
Base code red step: `claim_coordinator_claim "42"` writes `claimed:test-machine-1`;
`grep -Fxq "zbuild:claimed"` fails → `assert_fail` fires.

Also replaced the release check that used `grep "claimed:"` (which never matched
`zbuild:claimed`) with `! grep -Fxq "zbuild:claimed"` to properly verify removal.
The release check is trivially true on base code (since `zbuild:claimed` was never
written there), but the whole section fails via the label check above.

**Problem 2 (acceptance-gate finding 1):** `core/claim/claim.sh` was added to
`config/shape-change-paths.txt` but no test asserted this entry existed. Reverting
the file made every test pass.

**Fix:** Added assertion at the end of the unit test (before `cleanup_test_env`):
```bash
if grep -Fxq "core/claim/claim.sh" "$REPO_ROOT/config/shape-change-paths.txt"; then
    assert_pass "core/claim/claim.sh is listed in config/shape-change-paths.txt"
else
    assert_fail "core/claim/claim.sh is listed in config/shape-change-paths.txt" ...
fi
```
Base code red step: base code `config/shape-change-paths.txt` does not contain
`core/claim/claim.sh` → `grep -Fxq` fails → `assert_fail` fires.
No SPEC tag: there is no SPEC in this contract for shape-change-paths.txt content.
