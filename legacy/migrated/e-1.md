## New canonical location

- `scripts/lib/run-status-comment.sh` — the sidecar: gate, GitHub I/O
  (`rsc_comment_create` / `rsc_comment_patch` / `rsc_comment_find` /
  `rsc_upsert`), the tail loop, `main`.
- `scripts/lib/run-status-render.sh` — the pure renderer (events.jsonl → body).
- `core/pipeline/runner.sh` — `_runner_status_comment_spawn` / `_reap`.
- `scripts/zbuild status-comment` — the by-hand re-attach.

## What was lifted verbatim

- **One comment per run, mutated via PATCH** — `POST …/issues/{n}/comments`
  once (`--jq .id`), then `PATCH …/issues/comments/{id}` for every update.
- **Comment id persisted atomically** — `mktemp` + `mv` into
  `<state_dir>/status-comment.json` (legacy: `progress-comment.id`), restored
  from disk when the process that created it is gone.
- **Hidden HTML marker** — `<!-- zbuild-run-status run_id=… -->` on the first
  line (legacy: `<!-- SHIPWRIGHT-STAGE: … -->`), now also the key a restarted
  sidecar searches for so a run never gets a second comment.
- **30 s timeout per `gh` call, `|| true`** — every GitHub failure is logged
  and ignored; the run's exit status never depends on GitHub.

## What was NOT lifted

- `gh_init` (repo detection) → `zbuild_repo_slug` in `scripts/lib/identity.sh`.
- `gh_add_labels` / `gh_remove_label` / `gh_assign_self` → the daemon workflow
  and `plugins/claim-coordinator/github-labels`.
- `_ensure_base_branch_ref` → `scripts/lib/merge-base.sh` (#1655).
- `gh_build_progress_body` (per-stage table) → replaced by the newest-first
  row model of ADR-064; the table shape is not preserved.
- `gh_wiki_page`, `escape_markdown`, `_emit_inner_stage_event` — dropped.

## Legacy references left dangling (deliberate)

`legacy/scripts/sw-pipeline.sh`, `legacy/scripts/sw-loop.sh`,
`legacy/scripts/sw-lib-pipeline-github-test.sh` and
`legacy/scripts/sw-lib-pipeline-stages-test.sh` still `source` the removed
file. `legacy/` is frozen and never executed (`legacy/.shipwright-disabled`);
the pruning protocol removes the keeper's source, not every caller of it.
