What this lens looks for: where the change and what the issue asked for part ways — including the files or areas the issue's scope names, and the decisions made for it: a file the change edits that nothing asked it to touch, an edit inside an expected file that goes beyond what was asked (removing or rewriting unrelated content), work put somewhere other than where the issue said it goes, and a part of the issue the change leaves out.

Not a finding:
- a file the issue lists that the change did not need to touch: an issue lists files that might change;
- a test for something the issue asks for, and a file that test needs.

Where these problems come from: the issue's own words, set beside what the change does.

Severity, by example:
- critical: the change deletes or rewrites a part of the system the issue never mentions;
- high: it removes a check or behaviour the issue did not ask to change;
- medium: it changes a file nothing asked it to touch in a way that alters behaviour, or leaves out part of what the issue asked for;
- low: a cosmetic edit nothing asked for.
