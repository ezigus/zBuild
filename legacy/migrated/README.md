# Legacy Migration Tombstones

When a keeper from [../../docs/KEEPERS.md](../../docs/KEEPERS.md) passes its 5-test trial and its legacy source is removed by `git rm`, a tombstone is written here.

Format (one line):

```
<keeper-id> migrated to <new-path> on <YYYY-MM-DD> (issue #<N>)
```

`ls .` answers "what's done."
