# write-boundary-watch.txt — locations the engine sweeps for out-of-bounds writes
# after each stage dispatch (ADR-058 C9, #1809).
#
# One entry per line; blank lines and # comments are ignored.
# Format: <path>[ maxdepth:<N>]
# Variables are expanded at sweep time: ${VAR} references the runtime environment.
# ${TMPDIR:-/tmp} is expanded to TMPDIR when set, otherwise /tmp.
#
# Three-tier override (highest to lowest priority):
#   ZBUILD_WRITE_BOUNDARY_WATCH env var (path to alternative file)
#   ~/.zbuild/write-boundary-watch.txt (user/operator override — replaces)
#   this file (shipped engine default)
#
${HOME} maxdepth:1
${HOME}/.zbuild
# The system temp, restored once C10 landed. C9 originally dropped these two
# roots and said so plainly — "a real reduction in coverage; the originally
# measured defect was a stage writing to /tmp" — because two things made them
# unusable at the time. Both are now closed:
#
#   * env-scrub wipes every ZBUILD_* before a model spawn, so engine code in a
#     spawned child could not see ZBUILD_STAGE_SCRATCH and its temps landed
#     here. Those are the ENGINE's writes, and halting on them killed runs on
#     the engine doing its job. C10's run-scoped TMPDIR, pinned through the
#     scrub, puts them back inside the job folder.
#   * A concurrent unrelated process writing to /tmp — the busiest shared
#     directory on any machine — could kill a run outright, because `find
#     -newer` records when a file appeared and never who wrote it. The settle
#     probe now classifies those `unattributable` rather than halting.
#
# Restoring these WITHOUT both would be strictly worse than leaving them out.
# tests/unit/write-boundary-sweep-test.sh SPEC-4g pins the roots, SPEC-4h/4i pin
# the attribution rule and its guard; a revert of either must revert this too.
${TMPDIR:-/tmp} maxdepth:1
/tmp maxdepth:1
${PWD} maxdepth:1
# The engine root at 2, per the issue's sweep spec. _ZBUILD_WB_ROOT is set by
# core/pipeline/write-boundary.sh; the built-in fallback list already carried
# this entry, so without it here the shipped config swept less than the default.
${_ZBUILD_WB_ROOT} maxdepth:2
